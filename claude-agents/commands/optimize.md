# /loxilb-ui:optimize - Performance Optimization

Coordinate React-Arch, Component-Builder, and State-Management agents for system-wide performance optimization.

**Usage**: `/loxilb-ui:optimize "[scope] performance"`

**Orchestration**:
1. React-Arch-Agent: Profile and identify bottlenecks
2. Component-Builder-Agent: Refactor components for performance
3. State-Management-Agent: Optimize state updates and cache

**Use for**:
- Dashboard performance optimization
- Reduce unnecessary re-renders
- Improve page load times
- Bundle size optimization
- Memory leak detection and resolution

**Activation**: Reading orchestrator from ~/.claude/loxilb-ui-orchestrator.md
