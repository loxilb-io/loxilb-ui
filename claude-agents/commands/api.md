# /loxilb-ui:api - API Integration Expert

Activate the API-Integration agent for REST API connectors and React Query implementation.

**Usage**: `/loxilb-ui:api "API integration task"`

**Expertise**: React Query, API connectors, data fetching, error handling, cache management

**Use for**:
- Create API connectors (src/connector/)
- Implement React Query hooks (src/hooks/query/)
- Setup data fetching and caching strategies
- Handle API errors and retry logic
- Optimize query invalidation

**Activation**: Reading agent definition from ~/.claude/agent-api-integration.md
