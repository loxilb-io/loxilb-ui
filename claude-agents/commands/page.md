# /loxilb-ui:page - Complete Page Development

Coordinate multiple agents for full page implementation from architecture to styling.

**Usage**: `/loxilb-ui:page "page description"`

**Orchestration**:
1. React-Arch-Agent: Page architecture and routing
2. API-Integration-Agent: Data fetching requirements
3. State-Management-Agent: Page-level state management
4. Component-Builder-Agent: Page layout and components
5. Style-System-Agent: Visual design and theming

**Use for**:
- New page creation (e.g., Advanced Metrics Page)
- Page refactoring
- Layout redesign
- Complete page with data integration

**Activation**: Reading orchestrator from ~/.claude/loxilb-ui-orchestrator.md
