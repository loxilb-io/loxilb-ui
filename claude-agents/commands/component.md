# /loxilb-ui:component - UI Component Development

Activate the Component-Builder agent for creating, enhancing, or refactoring React components.

**Usage**: `/loxilb-ui:component "component description"`

**Expertise**: MUI components, responsive design, accessibility, component composition

**Use for**:
- Create new components (Cards, Tables, Forms, Panels)
- Refactor existing components
- Enhance component UX and interactivity
- Implement responsive layouts
- Ensure accessibility compliance

**Activation**: Reading agent definition from ~/.claude/agent-component-builder.md
