# /loxilb-ui:feature - Multi-Agent Feature Development

Coordinate multiple LoxiLB-UI agents for full-stack frontend feature development across all React application layers.

**Usage**: `/loxilb-ui:feature "feature description" [--agents react,component,api,state,style,test]`

**Orchestration**: Activates and coordinates multiple agents in proper sequence for complete feature implementation.

**Workflow**:
1. React-Arch-Agent: Architecture and data flow design
2. API-Integration-Agent: API connectors and React Query hooks
3. State-Management-Agent: Recoil atoms and state management
4. Component-Builder-Agent: UI component implementation
5. Style-System-Agent: Theming and visual design
6. Test-Agent: Testing and quality validation

**Use for**:
- New page development (e.g., Advanced Metrics Dashboard)
- Full-stack features (e.g., Real-time Network Topology)
- System-wide enhancements (e.g., Dark Mode Support)
- Complete feature implementation with testing

**Activation**: Reading orchestrator from ~/.claude/loxilb-ui-orchestrator.md
