# /loxilb-ui:enhance - Component Enhancement

Coordinate Component-Builder, Style-System, and Test agents for component improvements.

**Usage**: `/loxilb-ui:enhance "component name"`

**Orchestration**:
1. Component-Builder-Agent: Refactor component structure
2. Style-System-Agent: Update visual design
3. React-Arch-Agent: Optimize performance if needed
4. Test-Agent: Add/update tests

**Use for**:
- Improve existing components
- Add accessibility features
- Enhance UX and interactivity
- Performance optimization
- Visual redesign

**Activation**: Reading orchestrator from ~/.claude/loxilb-ui-orchestrator.md
