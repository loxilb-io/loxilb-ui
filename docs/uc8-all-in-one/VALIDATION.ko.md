# UC-8 실습 검증 범위

2026-10-28 전용 원격 Linux 환경에서 Gateway 554c7932, UI 12d5834d, OAM 46acdf7f를 소스에서 빌드해 기본 UI 실습과 정리를 검증했습니다. 빌드 캐시가 사용됐습니다.

- 두 합성 모델 listener의 키 허용·거부와 개별 backend 수신을 확인했습니다.
- 키 RPS 초과 및 회복, 모델별 TPM 초과 차단, 대기열 초과 및 대기 요청 처리를 확인했습니다.
- 정책 저장소 장애 중 UI 경고와 쓰기 거부, 복구 후 조회와 인증을 확인했습니다.
- PR #486이 반영된 Gateway를 cgroup 사전 마운트 우회 없이 같은 컨테이너에서 재시작해 cgroup2와 요청 복구를 확인했습니다.
- 실습 키·objective·rule UI 삭제, 키 폐기 후 401, tenant 중립화, 실습 프로젝트 자원 회수를 확인했습니다.

기존 단계별 캡처는 이전 Gateway 버전에서 촬영한 화면이며 일부 최신 리허설 화면을 추가했습니다. 실제 GPU 모델, 장기 공정성, 운영 환경 및 sockmap 가속 성능은 이 실습에서 검증하지 않았습니다. 소스는 고정되지만 기반 이미지와 패키지는 변할 수 있으며 이미지 ID의 재현을 보장하지 않습니다.
